# P-001 · 5 秒动效宣传片 — 制作提示词

> 交付给 Codex 的完整指令。目标：**严格 ≤ 5.000 秒**，中性极简底子上做中复杂度动作，
> 观感克制但细节经得起逐帧看。情绪：积极向上，不喊口号。
>
> **画幅：16:9 / 1920×1080**（已定稿）。竖屏版另开 P-004，不要在同一个工程里做响应式适配。

---

## 一、硬约束（先看这段，违反即返工）

| 项 | 要求 |
|---|---|
| 时长 | 总长 **≤ 5.000s**；最后一帧静止不得少于 0.45s，**不允许黑屏收尾** |
| 画幅 | **1920×1080**，16:9，横屏 |
| 帧率 | 60fps（首选，给缓动留余量）／30fps 可接受 |
| 安全区 | 左右各 **108px**（6%）、上下各 **97px**（9%）；主角元素与文字不得越界 |
| 音频 | **无**。不要加任何音效或背景乐，交付纯画面 |
| 文字 | 全片最多 1 行主文案 + 1 行小字，**全部左对齐**，不居中 |
| 禁止 | 弹跳（bounce）、抖动（shake）、旋转超过 15°、彩虹渐变、粒子爆散、镜头光晕、粒子星尘、"科技感"蓝色六边形网格 |

**为什么禁止这些**：它们是"廉价炫技"的视觉指纹。要的高级感来自**极少的元素 + 精确的时序 + 物理正确的运动**，不是叠加特效。

---

## 二、画幅换算：为什么不能等比缩放

从 1080×1920 换成 1920×1080，**不是把数字乘一遍**。宽高比从 0.5625 变成 1.778，差 3.16 倍：

- 竖屏是**纵向堆叠**：圆在上、线在中、字在下。
- 横屏纵向只有 1080px，堆三层会挤成一条；但横向多出 840px 空着。
- 所以横屏改成**左右两栏**：左边图形、右边文字。这是唯一能同时满足"留白充足"和"元素不缩水"的排法。

**尺寸锚定基准也从"宽度"改为"高度"**。横屏里纵向是最稀缺的维度，元素按高度定比例才不会被压扁。

## 三、版式网格（所有坐标以此为准）

```
画布        1920 × 1080
外边距      108（左右） ／ 97（上下）
内容区      x: 108 → 1812 ｜ y: 97 → 983
网格        12 列 × 120px，列间距 24px，合计 1704px
光学中心    y = 540（视觉正中，略高于几何中线，故意上提 0）
```

### 关键坐标

| 元素 | 数值 |
|---|---|
| 基准横线 | `y = 640`，`x: 384 → 1056`，长 672px |
| 圆形 | 直径 `200`，圆心 `(560, 540)`，底边正好落在 640 |
| 三个矩形 | `56 × 56`，底边 640，`x = 840 / 920 / 1000`（间距 24），右边正好收在 1056 |
| 弧线 | 三次贝塞尔 `M 420 748 C 640 748, 840 656, 1020 656`，左端平出、右端平收，净升高 92px |
| 主文案 | 左对齐起于 `x = 1200`，基线 `y = 560`，字号 72px，字重 600 |
| 副标 | 左对齐起于 `x = 1200`，基线 `y = 618`，字号 26px，字重 400 |

### 比例依据

- **圆 200 / 画高 1080 = 18.5%**。竖屏版是 180 / 1080（宽） = 16.7% 宽，按高度看是 9.4%——横屏不能照搬 9.4%，否则圆只有 100px，在大屏幕上像颗灰尘。取 18.5% 听起来大，但因为横屏视野宽，实际观感与竖屏相当。
- **矩形 56 / 1080 = 5.2%**，与圆的 200 之比为 3.57:1，与竖屏的 180:44 = 4.09:1 接近，保持同一"主次关系"。
- **线宽 6px 与圆角 12px 保持不变**。这是有意的：尺寸可以随画幅变，**笔画语言不能变**。全片只有一个线宽、一个圆角，这正是"简约"的来源。
- **文字块 600px 宽**（1200→1800），主文案 72px × 6 字 ≈ 432px，留 168px 呼吸。文字块与图形的间距 144px = 1.2 个列宽，这是横向呼吸的标准值。
- **橙色实际只占 0.1%**（两段线 168×6 = 2016px² ÷ 画布 2,073,600px²）。所以"≤3%"不是要你去凑面积，而是**上限约束：橙色只能出现在这条线上，全片不许加第二处橙**。168px 长的橙段在 1920 宽下已经足够跳出来，因为它周围全是单色。
- **弧线不用圆弧半径**，用三次贝塞尔：`M 420 748 C 640 748, 840 656, 1020 656`。两端切线都是水平的，中段加速抬起，读起来是"向上生长"而不是"拱门"。右端 656 停在橙线（680）上方 24px，留出清晰间隙。

## 四、视觉语言

### 调色
- 底色：`#F4F2ED`（暖白，不是纯白 —— 纯白廉价）
- 墨色：`#1A1A1A`（主元素）
- 唯一强调色：`#E85A2C`（朱橙），**全片累计出现面积不超过画面 3%**
- 不要阴影、不要发光、不要描边。层级靠**明度差**表达。

### 形态
- 只有三种几何原语：**圆**、**矩形**、**一段弧线**。
- 圆角统一 `r = 12px`；线条粗细只有一个值：`6px`。粗细变化是廉价感的来源。

### 字体
- 无衬线，字重对比大。中文优先 `思源黑体 / Noto Sans SC`；字距 +2%。
- 文案出现方式：**只做纵向 12px 的位移 + 透明度 0→1**，不做逐字弹入、不做打字机。

### 运动原则（全片成败关键）
1. **一次只动一个主角**。任何时刻画面里只有一组元素在运动，其余静止。
2. **缓动曲线只用两条**：
   - 进场 `cubic-bezier(0.22, 1, 0.36, 1)` —— 快进入、慢收尾
   - 退场/位移 `cubic-bezier(0.65, 0, 0.35, 1)`
   不要 `ease-in-out` 默认值，不要弹性（elastic）。
3. **重叠 3 帧**：上一元素到位前 3 帧，下一元素开始动。这个重叠是"不简约"的来源，但肉眼看不出，只觉得顺。**不要超过 4 帧**。
4. **幅度克制**：位移不超过 56px，缩放范围 0.94–1.00。

## 五、分镜时间轴（60fps，共 300 帧）

| 时间 | 帧 | 画面动作 | 细节要求 |
|---|---|---|---|
| 0.00–0.35s | 0–21 | 暖白底全屏。基准线从 `x=720` 向左右两端生长至 `384 / 1056` | 生长用进场曲线；两端为**平头**不是圆头。起点选 720 而非 560，让线条看起来"从画布中心向外"而非"从圆的位置" |
| 0.35–0.90s | 21–54 | 圆从线后"浮起"：透明度 0→1，同时从 `y=558` 上移到 `540`（+18px → 0） | 到位**没有回弹**，一次停稳 |
| 0.90–1.45s | 54–87 | 三个矩形依次从线下方升起至 `y=584`，间隔 8 帧，左→右 | 三者底边最终对齐 `y=640`；最后一个到位时前一个已完全停住 |
| 1.45–1.95s | 87–117 | **全画面完全静止 0.5 秒** | ⚠️ 必须有这 0.5s，它是节奏呼吸。不要用"轻微浮动"或"缓慢呼吸"填满，那是最常见的偷懒 |
| 1.95–2.60s | 117–156 | 横线从 `x=720` 裂成两段，各向左右再收 84px（各段最终长 168px），同时整体下移 40px 到 `y=680`；朱橙从裂点向两端扩散填充 | 橙线是**替换**关系不是叠加。全片橙色首次出现，面积约 1.4% 画布 |
| 2.60–3.30s | 156–198 | 圆与三矩形整体上移 56px（圆到 `y=484`，矩形到 `y=528`）；同时弧线自 `x=420` 起沿路径扫入至 `x=1020` | 弧线扫入用 `stroke-dashoffset`，不是缩放拉伸。弧线左端 `y=748`、右端 `y=656`，全程在橙线（680）下方或侧方，不与之交叉 |
| 3.30–4.10s | 198–246 | 主文案从 `y=572` 上移到 `560` 并淡入；副标延迟 10 帧，从 `y=630` 到 `618` 做同样动作 | 文案**只做一次**，之后完全不动 |
| 4.10–4.55s | 246–273 | 弧线整体下移 8px 并淡至 55%；橙线亮度 85%→100% | 收尾动作，几乎察觉不到 |
| 4.55–5.00s | 273–300 | **全静止**，保持终版构图 | 末帧干净、可直接截屏做 1920×1080 海报 |

> 文案占位：主文案 `一起，向前`；副标 `2026`。可替换，但**主文案不得超过 6 字**（72px 下 6 字 432px，7 字就要缩字号，破坏层级）。

## 六、构图检查清单（出片后自检）

- [ ] 逐帧看：有没有任何时刻两个以上元素同时在动？
- [ ] 0.5s 静止段是否真的完全静止？
- [ ] 橙色占比是否 < 3%？
- [ ] 所有圆角是否都是 12px？所有线宽是否都是 6px？
- [ ] 文字是否全部左对齐、且右侧有 ≥ 12px 余量（1800 → 1812 安全线）？
- [ ] 弧线左端 748 与橙线 680 的间隙是否清晰、右端 656 是否高过橙线 24px？
- [ ] 总时长是否 ≤ 5.000s（`ffprobe` 验证）？
- [ ] 最后一帧是否可独立作为静态图使用？
- [ ] 转成灰度后层级是否依然清晰？

## 七、技术建议（给 Codex）

- 首选 **Remotion**（React）：时序用 `interpolate` + 自定义 bezier；或 `spring({damping: 200})` 得到无过冲曲线。
- 备选：纯 SVG + CSS 动画 + `ffmpeg` 截帧；Manim 太重不推荐。
- **不要在组件里写 1920/1080 的逻辑**，改用 `useVideoConfig()` 读取宽高，所有坐标写成相对值的常量表（见第三节表格直接转成 TS 对象）。
- 导出：H.264，`-crf 16`，60fps，`-pix_fmt yuv420p`。
- 工程放 `projects/P-001-5s-splash/`，产物放 `out/v1.mp4`。

## 八、验收

1. `ffprobe -v error -show_entries format=duration -of csv=p=0 out/v1.mp4` ≤ 5.000
2. 抽帧检查 `0.35s / 1.45s / 2.60s / 3.30s / 4.90s` 五帧，坐标对照第三、五节
3. 主观：**连看三遍不觉得腻**。觉得腻就是动得太多——删动作，不要加。

## 九、一句话版本（直接喂模型用）

> 5 秒极简动效，1920×1080 横屏。暖白底 `#F4F2ED`，墨黑单色，仅一处朱橙点缀且占画面 3% 以内。左边是图形、右边是文字，左右两栏。图形只用圆（直径 200）、矩形（56×56 三个）、一条弧线，全部落在 y=640 这条基准线上；圆角恒为 12px、线宽恒为 6px。全片任何时刻只有一个元素在运动，缓动快进慢出、无回弹。节奏：线从中心向两侧长开 → 圆浮起 → 三个方块升起 → 完全静止半秒 → 线从中间裂开并染成朱橙 → 图形整体上移同时弧线扫入 → 右侧文案淡入 → 全静止收尾。最后 0.45 秒全静止，末帧可直接当海报。积极向上，克制，不加任何特效。
