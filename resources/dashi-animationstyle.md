## 能做什么

把一段**中文知识口播**做成 **7 种画风的讲解动画**。

- 画面由 Claude 写 HTML / Canvas 代码逐帧绘制，不用生图模型
- 适合把讲稿变成可视化讲解

**典型用途**：中文知识类口播视频、流程讲解。

## 不能做什么

不生成真人影像；不做产品 UI 演示。
